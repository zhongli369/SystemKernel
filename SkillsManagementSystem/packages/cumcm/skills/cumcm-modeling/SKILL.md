# CUMCM 数学建模分析

## 核心原则

国赛建模重**工程合理性**而非数学炫技。优先保证：可解释性 > 完整性 > 精度。

## 题型分类与模型选择

### 题型识别

拿到题目后，先按以下维度分类：

| 维度 | 选项 |
|------|------|
| 数据驱动/机理驱动 | 有数据 → 数据驱动；无数据 → 机理建模 |
| 问题类型 | 预测 / 评价 / 优化 / 图论网络 / 统计分析 / 微分方程 |
| 时间维度 | 静态 / 动态 |
| 约束条件 | 有明确约束 → 优化类；无约束 → 分析类 |

### 模型选择决策树

```
问题类型？
├── 预测类 (已有历史数据，需预测未来)
│   ├── 数据量 < 30：灰色预测 GM(1,1)
│   ├── 数据量 30-200，线性趋势：回归分析
│   ├── 数据量 30-200，周期性强：ARIMA / SARIMA
│   ├── 数据量 > 200，非线性：XGBoost / LightGBM
│   └── 仅在有充分 GPU 和调参经验时：LSTM
│
├── 评价类 (多对象、多指标、选最优)
│   ├── 指标权重已知 → TOPSIS
│   ├── 指标权重未知 → 熵权法 + TOPSIS
│   ├── 指标有层次结构 → AHP (层次分析法)
│   ├── 评价标准模糊 → 模糊综合评价
│   └── 多方法组合：熵权-AHP混合赋权 + TOPSIS
│
├── 优化类 (有目标函数和约束条件)
│   ├── 线性目标+线性约束 → 线性规划 (pulp/cvxpy)
│   ├── 整数/0-1变量 → 整数规划
│   ├── 非线性目标或约束 → 非线性规划 (scipy.optimize)
│   ├── 多阶段决策 → 动态规划
│   └── NP-hard，精确解不可行 → GA / SA / PSO (遗传/模拟退火/粒子群)
│
├── 图论/网络类
│   ├── 最短路径 → Dijkstra / Floyd
│   ├── 最小生成树 → Prim / Kruskal
│   ├── 最大流/最小费用流 → Ford-Fulkerson / 网络单纯形
│   ├── TSP/VRP → 遗传算法 / 蚁群算法 / LKH
│   └── 复杂网络分析 → networkx (中心性、社区检测)
│
├── 统计分析类
│   ├── 降维需求 → PCA (主成分分析)
│   ├── 无标签分组 → K-Means / DBSCAN / 层次聚类
│   ├── 两总体均值比较 → t检验
│   ├── 多总体比较 → 方差分析 (ANOVA)
│   └── 因素影响判断 → 回归分析 + 显著性检验
│
└── 微分方程类 (物理/生物/经济动态系统)
    ├── 常微分方程 → 解析解 / 数值解 (odeint)
    ├── 偏微分方程 → 有限差分 / 有限元
    └── 传染病模型 → SIR / SEIR
```

### 模型选择注意事项

1. **灰色预测 GM(1,1)**：国赛高频，数据量少时首选，简单且论文好写
2. **TOPSIS + 熵权法**：评价题标配组合，稳定且结果可靠
3. **线性/整数规划**：优化题首选精确方法，不得已再用启发式
4. **XGBoost/LightGBM**：大数据预测时优于传统回归，但必须做特征重要性解释
5. **LSTM**：仅数据量 > 5000 且有明显时序依赖时使用，否则论文评审时会质疑"为什么不用更简单的方法"

## 建模标准流程

### 1. 问题形式化 (Formalization)

```
输入：题目自然语言描述
输出：形式化数学描述

步骤：
- 定义所有变量 (符号 + 含义 + 单位)
- 定义目标函数 (若有)
- 定义约束条件 (若有)
- 列出假设
```

### 2. 模型假设

假设必须：
- **可辩护**：能解释为什么合理
- **简化计算**：不引入不必要的复杂性
- **不过度**：不能假设掉问题的核心特征

常见合理假设：
- 数据真实可靠
- 系统在一定时间/空间范围内稳定
- 忽略次要因素的微小影响
- 各因素间独立性 (需检验)

### 3. 模型建立

推导格式：
```
Step 1: 从假设出发，建立基本关系
Step 2: 逐步推导，每一步标注引用的假设或定理
Step 3: 得出最终模型表达式，标注公式编号
Step 4: 说明模型参数含义及取值范围
```

### 4. 模型求解

- 说明求解方法 (算法名称 + 原理简述)
- 给出关键参数设置及依据
- 展示收敛性/最优性证明或验证
- 给出求解结果

### 5. 敏感性分析

对关键参数 ±10%、±20% 扰动：
- 绘制参数-结果变化曲线
- 识别敏感参数
- 解释为何某些参数敏感/不敏感
- 给出参数选择的建议区间

### 6. 模型评价

**优点** (3-5条)：
- 结果精度
- 计算效率
- 可解释性
- 可推广性

**缺点** (2-3条，诚实)：
- 假设局限性
- 数据依赖性
- 计算复杂度

**改进方向** (2-3条)：
- 放松某个假设
- 使用更精细的数据
- 扩展模型维度

## 禁止事项

- 模型比问题更复杂 (overkill)
- 无法解释参数来源
- 忽略模型的数学前提 (如正态性、独立性)
- 堆砌多个模型而不比较
- 使用黑盒模型却不做可解释性分析
- 敏感性分析缺失
