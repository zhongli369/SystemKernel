# CUMCM 国赛论文写作

## 核心原则

> **摘要决定上限。** 评审第一印象来自摘要，摘要差则全文无望高分。

论文优先级：完整性 > 逻辑清晰 > 图表规范 > 语言精致。

## 论文结构 (国赛标准)

```
标题
摘要 (一页以内，最重要)
关键词 (3-5个)
───────
一、问题重述
二、模型假设与符号说明
  2.1 模型假设
  2.2 符号说明
三、问题一：<小标题>
  3.1 问题分析
  3.2 模型建立
  3.3 模型求解
  3.4 结果分析
四、问题二：<小标题>
  (同上结构)
五、问题三：<小标题>
  (同上结构)
六、敏感性分析
七、模型评价与改进
  7.1 模型优点
  7.2 模型缺点
  7.3 改进方向
八、结论
参考文献
附录 (代码/数据)
```

## 各章节写作规范

### 摘要 (最重要)

**结构**：一段式，约 800-1000 字，包含：

```
针对 [题目背景]，本文建立了 [模型1]、[模型2] 和 [模型3]，
分别解决了 [问题1]、[问题2] 和 [问题3]。

问题一：采用 [方法] 建立 [模型]，通过 [求解方法] 求解，
      得到 [关键数值结果]。

问题二：在问题一基础上，引入 [新因素]，建立 [模型]，
      得到 [关键数值结果]。

问题三：考虑 [额外约束]，建立 [模型]，
      得到 [关键数值结果]。

敏感性分析表明，[关键发现]。

本文模型具有 [优点1]、[优点2]，但存在 [缺点]，
可进一步 [改进方向]。

关键词：关键词1；关键词2；关键词3；关键词4；关键词5
```

**摘要铁律**：
- 必须包含具体数值结果 (评审者直接看数字)
- 必须体现模型亮点 (与标准方法的区别)
- 必须简短精炼 (一段式，不分段)
- 包含 3-5 个分号分隔的关键词

### 问题重述

- 用自己的话重述，不要抄原题
- 提炼核心问题，而非复述细节
- 3-5 句话即可
- 最后一句："本文需要解决以下问题：..."

### 模型假设

每条假设必须：
1. 编号
2. 陈述假设内容
3. **解释为什么合理** (一行即可)

```markdown
1. **假设数据真实可靠**：题目提供的数据经权威机构采集，
   数据预处理阶段将进行异常值检测以保证数据质量。

2. **假设系统在观测期内稳定**：观测时间跨度较短，
   系统结构未发生显著变化，此假设合理。
```

### 符号说明

使用三线表：

| 符号 | 含义 | 单位 |
|------|------|------|
| $x_i$ | 第 $i$ 个样本的特征值 | — |
| $w_j$ | 第 $j$ 个指标的权重 | — |
| $S$ | 综合得分 | — |

### 模型建立与求解 (每问)

论文核心部分。结构：

```
3.1 问题分析
  - 分析问题本质 (预测/评价/优化/...)
  - 确定解题思路
  - 解释为什么选择这个模型

3.2 模型建立
  - 给出数学模型 (公式编号)
  - 定义目标函数、约束条件
  - 解释模型参数含义

3.3 模型求解
  - 说明求解算法
  - 给出关键参数
  - 展示求解结果 (表格/图表)

3.4 结果分析
  - 分析结果含义
  - 与常识/预期对比
  - 解释异常值
```

**公式规范**：
- 行内公式：`$...$`
- 行间公式（需引用）：`\begin{equation} ... \label{eq:xxx} \end{equation}`
- 多行公式：`\begin{align} ... \end{align}`
- 矩阵：`\begin{bmatrix} ... \end{bmatrix}`

### 敏感性分析

- 选择 2-3 个关键参数
- 在 ±10%、±20% 范围内扰动
- 绘制参数-结果变化曲线
- 给出结论："模型对参数 X 较为敏感/不敏感，这是因为..."

### 模型评价

```markdown
7.1 模型优点
  (1) [优点1]：[简短解释]
  (2) [优点2]：[简短解释]
  (3) [优点3]：[简短解释]

7.2 模型缺点
  (1) [缺点1]：[简短解释]
  (2) [缺点2]：[简短解释]

7.3 改进方向
  (1) [改进1]
  (2) [改进2]
```

### 结论

- 一句话回顾主要工作
- 总结各问题的最终结果
- 一句话展望

## 图表编号规范

- 图：`图 1`、`图 2`... (Figure → 图)
- 表：`表 1`、`表 2`... (Table → 表)
- 公式：`(1)`、`(2)`... 
- 图表必须有标题：表标题在上方，图标题在下方

## 引用规范

```latex
% 参考文献
\begin{thebibliography}{99}
\bibitem{ref1} 作者. 文章标题[J]. 期刊名, 年份, 卷(期): 页码.
\bibitem{ref2} 作者. 书名[M]. 出版地: 出版社, 年份.
\bibitem{ref3} 作者. 论文标题[D]. 学校, 年份.
\end{thebibliography}
```

国赛参考文献 5-10 篇即可。

## 语言规范

- 全程使用"本文""我们"，不使用"我"
- 数学语言严谨："设...""令...""由...得...""可证..."
- 避免口语化："很多"→"大量"，"差不多"→"近似"
- 术语统一：同一概念全文用同一术语
- 不使用"显然""易证"等无依据的词汇 (除非确实 trivial)

## 常见扣分项

- 摘要无具体数值 (扣分严重)
- 图表编号混乱
- 公式未编号
- 符号说明与正文不一致
- 结果分析只说"结果很好"，不给原因
- 缺少敏感性分析
- 模型评价只写优点不写缺点
- 参考文献格式混乱
- 缺少关键词
- 字数过少 (< 15页)
